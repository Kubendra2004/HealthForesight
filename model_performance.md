# Model Development Metrics

> **Use limitation:** These metrics come from small repository datasets and internal holdout or rolling time-series validation. They are development checks, not independent clinical validation. Do not use model scores alone to diagnose, treat, or make staffing decisions.

The reports below are generated by the training scripts and saved under `backend/models/artifacts/`. Re-run the matching script to refresh them. Seeds and split sizes are recorded with the metrics.

## Heart disease classification

Training used 303 rows from `Heart_disease_cleveland_new.csv`, with 242 rows for model selection and 61 held out. A 5-fold stratified search selected the Random Forest by balanced accuracy.

| Measure | Development result |
| --- | ---: |
| 5-fold CV balanced accuracy | 81.9% |
| Holdout accuracy | 88.5% |
| Holdout balanced accuracy | 88.9% |
| Holdout ROC AUC | 96.0% |
| Holdout baseline balanced accuracy | 50.0% |

The 61-row holdout is too small to establish general performance. The holdout Brier score is recorded in `heart_model_metrics.json`; probability calibration has not been independently evaluated.

The holdout has 20 female and 41 male records. Balanced accuracy was 92.9% for female records and 85.1% for male records, based on these small subgroup counts only.

## Diabetes classification

Training used all 520 rows and both gender groups in `diabetes_data_upload.csv` (192 female, 328 male). The 104-row holdout contains 38 female and 66 male records. The model was selected by 5-fold stratified balanced accuracy.

| Measure | Development result |
| --- | ---: |
| 5-fold CV balanced accuracy | 96.9% |
| Holdout accuracy | 98.1% |
| Holdout balanced accuracy | 98.4% |
| Holdout ROC AUC | 100.0% |
| Female holdout balanced accuracy | 100.0% (n=38) |
| Male holdout balanced accuracy | 96.7% (n=66) |

The female holdout contains only four negative cases, so its subgroup score is highly uncertain. The dataset is small and does not establish performance across clinical settings or populations. The saved encoder now supports both dataset categories, but that is not evidence of clinical generalizability.

## Resource forecasts

Prophet forecasts were evaluated with a 450-day initial window, 7-day horizon, and rolling cutoffs on 719 observations from `resources_ai.csv` (70 held-out forecast points per target). MAE is compared to a baseline that repeats the most recent observed value at each cutoff.

| Target | Prophet MAE | Baseline MAE | MAE improvement over baseline |
| --- | ---: | ---: | ---: |
| Beds | 13.43 | 19.47 | 31.0% |
| ICU | 4.06 | 7.00 | 42.0% |
| Oxygen | 12.25 | 18.74 | 34.6% |
| ER visits | 7.63 | 12.21 | 37.5% |
| Occupancy rate | 0.0191 | 0.0320 | 40.2% |

These results describe this dataset and evaluation window only. They do not establish reliable real-world forecasts; verify forecasts against local operations data before operational use.

## Clustering and other models

Patient clustering is exploratory and has no validated clinical outcome. Readmission and ICU transfer artifacts do not have reproducible training and evaluation pipelines in this repository, so no performance figures are reported for them.
